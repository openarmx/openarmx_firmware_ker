# OpenArmX KER Firmware v3.3.0

本版本将 M5 固件统一为单一运行时镜像，并支持 USB/WiFi 无重启切换。

## 主要更新

- M5 默认使用 USB Vendor 传输，可通过 KER Studio 随时切换 USB/WiFi。
- USB 与 WiFi 切换无需重启；WiFi 连接失败 15 秒后自动回退 USB。
- USB 使用 CDC + Vendor 复合设备，可同时进行上位机配置和 ROS 关节数据传输。
- WiFi 配置和当前传输模式保存到 NVS，支持 `openarm-ker.local:19090` 访问。
- 提供 Encoder ID 1-16 的独立 HEX 固件。
- 提供可从 `0x0` 烧录的 ESP32-S3 DIO 完整合并镜像。
- 包含版本清单与 SHA256 校验文件。

## 下载

普通用户建议下载 `openarmx-ker-firmware-v3.3.0.zip`。KER Studio 可从此 Release 自动获取固件。

烧录前可使用 `SHA256SUMS` 校验下载文件。
